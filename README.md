# Swing_P02_comprendio
## Descripción del proyecto
Buenas, esta es mi Aplicación para la gestión de apartamentos turísticos, MalosSon, la aplicación trata de gestionar reservas para un apartamento turístico en cualquier provincia de España, con un formulario y con opciones para guardar, imprimir o crear uno nuevo, todavía no esta implementado la opción de dar de baja que se implementara en un futuro.

## Contenido de la publicación
La estructura de este repositorio es la siguiente:

* **desarrollo**: Contiene el código fuente del proyecto.
* **ejecutable**: Contiene el archivo `.jar` para ejecutar la aplicación directamente.
* **documentación técnica**: Javadoc generado del código fuente.
* **documentos**: Documentación relativa a la usabilidad de la aplicación.

## Desarrollo del proyecto
* **Entorno de Desarrollo**: Eclipse IDE 2025 09
* **Lenguaje**: Java

## Despliegue
Para ejecutar la aplicación, sigue los siguientes pasos:

### Windows
1. Descarga la carpeta `ejecutable`.
2. Haz doble clic sobre el archivo `.jar`.

### Línea de comandos
Sitúate en la carpeta donde está el ejecutable y escribe:
```bash
java -jar GestionApartamentos.jar
```
